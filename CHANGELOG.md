# Changelog

## 1.0.0 · 21 Nov 2026

First public release.

- **Exact target maths.** "What you need" is now solved over the official grade steps with every module grade truncated, as the portal does. The old linear estimate on raw grades could ask for a better grade than needed.
- **German.** Every view and the popup in English and German. Follows the browser language; switch in any view.
- **New look.** Colours, type and shapes from omkarkhadilkar.dev, IBM Plex bundled with the extension, dark mode for the panels and the popup.
- **Release files.** MIT licence, Chrome Web Store listing and screenshots (`store/`), `npm run build` for the upload zip.
- **Tests.** 25 unit tests; browser tests now also load the built extension in Chrome against a stand-in FOM page.

## 0.4.0 · 9 Nov 2026

Three views (Basic, Inline, Advanced), per-module what-if, target setter, final range, exam countdown.
